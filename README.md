# landolytics-lite

The current Landolytics API is written in Python, only exposes simple scoreboard
information for College and NFL games, and was primarily written with the use of AI
coding agents. This repo is going to be a personal challenge to rewrite that API, as
well as expose additional relevant game information, in a Go API written entirely by
hand.

Is it beneficial to the site to rewrite the API over and over? Nope. Is this a good use
of my time? Hard to say. But we're going to do it anyways :)
